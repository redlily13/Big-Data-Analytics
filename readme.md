## 1. Project Overview

This project implements an Apache Hadoop MapReduce application to process and analyze students' examination marks across two execution models:

1. **Hadoop Streaming in Python (Apache Hadoop 3.4.1 on Google Colab):** Reads raw subject-level examination scores from `students.csv` and calculates subject-wise student count, average marks, highest mark, lowest mark, pass count (marks of at least 40), and fail count (marks below 40) into `student_marks_results.csv`.
2. **Native Java MapReduce (`StudentMarksAnalysis.java`):** Reads student examination records from `student_marks.txt` in HDFS and computes each student's total score, average percentage, and final academic grade.

## 2. Repository Structure

* `student_marks_results.csv` — Final subject-wise output CSV generated by the Hadoop Streaming job.
* `students.csv` — Input examination dataset (15 records across 5 students and 3 subjects).
* `mapper.py` — Python Mapper script that reads CSV rows from standard input and emits tab-separated subject and mark pairs.
* `reducer.py` — Python Reducer script that aggregates marks by subject and outputs summary statistics.
* `Student_Marks_Hadoop_MapReduce.ipynb` — Complete 22-step Google Colab practical notebook.
* `StudentMarksAnalysis.java` — Complete Java MapReduce source code containing the Mapper, Reducer, and Driver classes.
* `student_marks.txt` — Input dataset for the Java MapReduce implementation.
* `index.html` — Interactive web dashboard displaying the MapReduce results and visualizations.
